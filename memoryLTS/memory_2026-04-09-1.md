## System Rules v3 — Manual de la Fábrica de Sitios Premium

Documento de referencia creado en abril 2026. Extrae los estándares validados en el primer proyecto (Cortina Studio).

### Stack obligatorio
- **Next.js 14+** App Router (nunca Pages Router), TypeScript `strict: true + noUncheckedIndexedAccess`
- **Tailwind CSS** único sistema de estilos — sin CSS-in-JS. shadcn/ui copiado al repo, no como dep
- **Framer Motion** para animaciones, lucide-react para íconos
- **WordPress Headless + WPGraphQL + Apollo Client + graphql-codegen**
- **React Hook Form + Zod**, next-intl (es default / en), next-sitemap + Metadata API

### Estructura de carpetas
`app/[locale]/`, `components/{ui,sections,layout,motion}`, `lib/{graphql,wordpress,validators}`, `messages/{es,en}.json`

**Regla crítica:** toda lógica de fetch vive en `/lib/wordpress/`. Los componentes de sección reciben props tipadas y no hacen fetch.

### Design tokens y sistema visual
- Tokens en `tailwind.config.ts` derivados de `client-brief.json` — prohibido hex hardcodeado en JSX
- Tokens universales que NO cambian por cliente: `shadow-{soft,medium,strong}`, `ease-premium` (`cubic-bezier(0.22,1,0.36,1)`), `rounded-xl` mínimo en botones
- Escala tipográfica: tracking negativo en headings grandes, `font-display` italic para subtítulos, `text-sm leading-relaxed text-foreground/55` para body

### Anatomía de sección (blueprint obligatorio)
Toda sección: `py-24 lg:py-32`, container `mx-auto max-w-7xl px-6 lg:px-8`, encabezado siempre con:
1. Eyebrow — `text-xs font-semibold uppercase tracking-[0.18em] text-accent`
2. H2 — `text-3xl lg:text-4xl font-semibold text-balance tracking-tight`
3. Subtitle — `font-display italic leading-relaxed text-{variant}/55`
4. Divider — `mx-auto mt-6 h-px w-12 bg-accent`

Fondos nunca se repiten consecutivamente: alterna light / soft / dark.

### Sistema de animación Framer Motion
- Easing universal: `[0.22, 1, 0.36, 1]` en **todas** las animaciones
- `FadeIn` — scroll-triggered, `viewport: { once: true, margin: '-64px' }`, offset y=20
- `FadeInStagger` — stagger 0.08–0.15 según cantidad de items
- Hero — usa `animate` (no `whileInView`), delays escalonados: eyebrow=0, H1=0.1, divider(scaleX)=0.22, subtitle=0.25, CTAs=0.38
- `prefers-reduced-motion` obligatorio: hook + media query global en `globals.css`

### Header y Footer (patrones fijos)
- Header: `fixed inset-x-0 top-0 z-50 h-20`, transparente sin scroll → `bg-background/95 backdrop-blur-md shadow-soft` con scroll >20px
- Footer: 3 zonas — CTA strip (`py-14`) + main grid 4 cols (`py-16`) + bottom bar (`py-6`), siempre `bg-primary`

### Reglas de código
- RSC por defecto, `"use client"` solo si usa estado/efectos/Framer Motion interactivo
- Botones: `rounded-xl px-7 py-3.5 shadow-medium hover:-translate-y-0.5 active:translate-y-0`
- Cards: `rounded-2xl p-7 border border-border/60 shadow-soft hover:-translate-y-1.5 hover:border-accent/35`
- `strokeWidth={1.75}` en iconos lucide (punto dulce entre default 2 y demasiado fino)

### Flujo de trabajo por cliente
1. Leer `client-brief.json` → 2. Configurar `tailwind.config.ts` → 3. next-intl → 4. globals.css → 5. Motion wrappers → 6. Header + Footer → **PAUSA y aprobación explícita** → 7. Secciones una por una

### Lo que NO hacer
Dos secciones con el mismo fondo, padding < py-24, botones con px-4, hex hardcodeado, fetch en componentes, queries inline, Pages Router, `any` en TypeScript, reducir whitespace "para ahorrar espacio".

**Why:** El whitespace ES el diseño premium. Un sitio genérico usa py-12; uno premium usa py-24 lg:py-32. La diferencia es palpable sin ser obvia.

**How to apply:** Consultar este documento (vía skill `diseno-fabrica`) antes de proponer cualquier sección o componente nuevo.
